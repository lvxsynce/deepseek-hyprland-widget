# DeepSeek виджет для Hyprland

Маленькое окошко с DeepSeek, которое всегда висит в фоне, а по хоткею
выскакивает прямо посередине экрана поверх всего, что ты сейчас делаешь.

Один раз логинишься — и всё. Дальше `Super + Shift` и пишешь нейросети,
не переключаясь на браузер.

## Что получится

```
 Super + Shift  →  окошко 600x650 по центру поверх всего
 Super + Shift  →  окошко спряталось обратно в фон
```

Приложение запускается само при входе в систему, так что браузер каждый
раз открывать не надо.

## Нужно

- Hyprland
- chromium / google-chrome / chromium-browser

## Ставим

```bash
git clone https://github.com/lvxsynce/deepseek-hyprland-widget.git
cd deepseek-hyprland-widget
./install.sh
```

Скрипт сам:

- кладёт скрипт в `~/.config/hypr/scripts/`
- кладёт `.desktop` файл, чтобы DeepSeek был в меню приложений
- добавляет правило окна в `~/.config/hypr/config/rules.conf`
- добавляет хоткей и автозапуск

Всё что он меняет, он бэкапит в `*.bak`. После установки:

```bash
hyprctl reload
```

Нажми `Super + Shift`. Откроется DeepSeek. Залогинься один раз.

Всё, готово. Больше ничего настраивать не надо.

## Если хочется поменять

| Хочу | Где править |
|---|---|
| Другое окно (клавишу) | `bind` в твоём hypr-конфиге или `settings.json` |
| Другой размер | `size = 600 650` в `rules.conf` |
| Чтобы не запускалось само | убери строку с `chromium` из автозагрузки |

## Если не работает

**Окошко открывается на весь экран.** Правило окна не сработало.
Проверь что в `rules.conf` совпадает именно `chrome-chat\.deepseek\.com.*`.
Chromium на Wayland игнорирует `--class`, имя окна у него другое.

**При нажатии ничего не происходит.** Посмотри лог:

```bash
hyprctl clients -j | grep -i deepseek
```

Если пусто — приложение не запустилось. Попробуй запустить руками
из терминала, чтоб увидеть ошибку.

**DeepSeek слетел.** Сессия лежит в `~/.config/deepseek`. Не удаляй эту
папку, если не хочешь логиниться заново.

## Удаляем

```bash
./uninstall.sh
hyprctl reload
```

## Как это устроено

Никакой магии, всё на голом Hyprland:

- **special workspace** `special:ai` — воркспейс, который рисуется
  поверх текущего. Поэтому окошко всегда выше других окон.
- **windowrule** — говорит Hyprland: окно с таким классом всегда плавающее,
  по центру, размер 600x650, и живёт в `special:ai`.
- **отдельный профиль chromium** (`--user-data-dir`) — чтобы куки DeepSeek
  не мешались с твоим обычным браузером.
- **скрипт** — если окно ещё не запущено, запускает его, иначе просто
  переключает special workspace.

## Ещё

- DeepSeek периодически ломает вёрстку и Cloudflare может показать капчу.
  Тогда просто перезапусти окно — починится.
- Если надоест держать браузер, есть вариант через API с ключом
  (бесплатные лимиты дают на platform.deepseek.com). Но это уже другая история.
